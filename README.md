## 🧠 About Me

I'm a **Software Engineer** passionate about deep technical challenges, static analysis, and building powerful developer tools. I am the creator of **N3MO**, a structural code intelligence layer that parses code into queryable knowledge graphs. 

I enjoy diving deep into ASTs, PostgreSQL optimizations, and building tools that eliminate regression risks and empower AI agents with true structural understanding of codebases.

> 🎯 **Core mindset:** Clean architecture · Scalable systems · Structural Analysis
