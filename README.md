## Shipped

### ◈ N3MO · `shipped · open source`

> A high-performance code intelligence engine that transforms any repository into a queryable, symbol-centric knowledge graph. Drop it into your CI, get blast-radius impact reports on every PR — automatically.

- **27 languages** · Python, Go, Rust, Java, TypeScript, Kotlin, Ruby, C/C++, and more
- **MCP server** · works natively with Claude Desktop, Cursor, and any MCP-compatible agent
- **Tree-sitter AST** · real symbol extraction, not regex hacks
- **Pre-incubated @ DTU IIF**

### ◈ Noir · `shipped · Windows`

> An advanced per-application audio patchbay and system router for Windows. Glassmorphic dark UI with real SVG cable connections between apps and endpoints.

- **Spider patchbay** · drag cables between apps and audio outputs in real time
- **Automation engine** · app launch/exit triggers, smart volume ducking
- **WASAPI low-latency** mixing · waveform and VU visualizers
- **4 themes** · Midnight Velvet, Cyberpunk Neon, Emerald Matrix, Solar Amber
