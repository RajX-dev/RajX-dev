I'm a **final-year B.Tech student** at Delhi Technological University and the founder of **N3MO**, a structural code intelligence engine that powers AI agents with deep codebase understanding. I'm passionate about static analysis, ASTs, and building developer tools that eliminate regression risks.

Currently pursuing **founding engineer roles** at YC-backed startups while exploring opportunities through campus placements and the Antler accelerator.
